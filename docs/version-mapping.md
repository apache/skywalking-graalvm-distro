# Version Mapping

Maps each distro release to the upstream Apache SkyWalking version it is built from.

When the submodule commit matches an upstream release tag, the upstream version is shown directly.
Otherwise, it is shown as `{commit-id}-SNAPSHOT` indicating a development build ahead of the last release.
